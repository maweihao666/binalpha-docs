更新日期：2026-10-19。

本仓库面向项目同学提供模型接入、维护流程和验收说明。仓库从全新首次提交建立，只保存公开文档；未导入原维护仓库的 Git 历史或源码压缩包。

## 如何参与

发现文档问题可以提交 Issue。修改文档可 Fork 本仓库、创建分支，再提交 Pull Request，由项目维护者审核后合并。

需要项目源码或部署权限时，请联系项目所有者安排私有授权交接。供应商 API Key、平台登录凭证、资源访问 Token 和用户数据通过私有渠道管理，不放入 Issue、PR 或文档。

## 上传约定

本仓库只接收公开说明文档。提交前检查差异，避免添加源码压缩包、完整源码、私有配置、会话数据或运行日志。`.gitignore` 已排除常见凭证与归档扩展名，但它不能阻止所有误上传，网页上传也必须人工检查。

测试记录只代表文档列出的环境和用例，不代表所有模型、数据源、日期和策略均通过验证。实际维护以当前部署版本和验证结果为准。
